## 架构说明

由Python编写，用户态杀毒软件，未使用不稳定的驱动内核。
本杀毒软件的拦截构建分为 **EDR** 和 **Endpoint**，虽然不能和 PYAS、XiguaSecurity 对标。

- 动态分析和静态拦截
- 单 EDR 架构为初版时使用  
  （此开源版本为最新上传的版本，但“最新上传不等于最新”；旧版已被遗弃、删除）
- 由于代码维护性太差（屎山），可以用拆分器把模块拆开查看
